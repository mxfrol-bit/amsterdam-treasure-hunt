### 1. ❌ → ✅ Баг карты исправлен!

**Проблема:** Карта не растягивалась на весь экран, нужно было переворачивать телефон

**Решение:**
```javascript
// Добавлены принудительные resize'ы
map.on('load', () => {
    setTimeout(() => map.resize(), 100);
});

window.addEventListener('resize', () => map.resize());
window.addEventListener('orientationchange', () => {
    setTimeout(() => map.resize(), 200);
});
```

**Файл:** `app-fixed.js`

### Интеграция в админку:

В `admin.html` уже есть кнопки генерации, но нужно подключить к backend:

```javascript
// Замените URL на ваш backend
const BACKEND_URL = 'http://localhost:3000';

async function generateContent(id) {
    const response = await fetch(`${BACKEND_URL}/api/generate-content`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ treasure_id: id })
    });
    
    if (response.ok) {
        alert('Контент сгенерирован!');
        await loadTreasures();
    }
}
```

## 📞 ПОДДЕРЖКА:

### Если что-то не работает:

1. **Карта не на весь экран:**
   - Проверьте что используете `app-fixed.js`
   - Очистите кэш браузера (Ctrl+Shift+R)

2. **Генерация не работает:**
   - Проверьте что backend запущен (`npm start`)
   - Проверьте URL в админке (localhost:3000)

3. **Точки не видны:**
   - Проверьте что `active = true` в базе
   - Проверьте координаты (lat, lng)

4. **Ошибки в консоли:**
   - Откройте DevTools (F12)
   - Проверьте Network tab
   - Проверьте Console tab
