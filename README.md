# 🗺️ Охота за сокровищами - Нижний Новгород

Улучшенная версия с новыми функциями!

## 🆕 Новые возможности

### 1. **Боковое меню (☰)**
- Профиль пользователя
- Достижения
- Таблица лидеров
- Настройки
- Помощь

**Как открыть:** Нажмите на иконку гамбургер-меню (☰) в левом верхнем углу.

### 2. **Кнопка закрытия просмотра точки (×)**
Теперь при просмотре точки сокровища появляется кнопка закрытия (крестик) в правом верхнем углу панели. Нажмите на нее, чтобы вернуться к основному экрану и карте.

### 3. **AI-генерация изображений для точек**

#### Как это работает:
- Когда вы открываете точку сокровища, автоматически генерируется уникальное изображение
- Используется Unsplash API для получения релевантных фотографий на основе названия и описания точки
- Изображения сохраняются в базе данных, чтобы не генерировать их повторно
- Можно отключить эту функцию в настройках

#### Настройка AI-генерации:
1. Откройте меню (☰)
2. Перейдите в "Настройки" (⚙️)
3. Найдите переключатель "🤖 Генерация AI-изображений"
4. Включите или отключите по желанию

### 4. **Настройки приложения**

В настройках доступны следующие опции:
- **🔊 Звуковые эффекты** - включить/отключить звуки при находке сокровищ и достижениях
- **📳 Вибрация** - включить/отключить вибрацию при событиях
- **🤖 Генерация AI-изображений** - автоматическое создание изображений для точек
- **🗺️ Показать все точки** - скрыть или показать уже найденные сокровища на карте

## 🔧 Технические улучшения

### Структура файлов:
```
├── index.html          # HTML с новым меню и элементами
├── style.css           # Стили с анимациями и компонентами меню

```

### Новые функции в коде:

**JavaScript (app.js):**
- `toggleMenu()` - открытие/закрытие бокового меню
- `closeTreasureView()` - закрытие просмотра сокровища
- `generateAIImage(treasure)` - генерация изображения для точки
- `fetchUnsplashImage(treasure)` - получение изображения из Unsplash
- `saveTreasureImage(treasureId, imageUrl)` - сохранение URL изображения
- `loadSettings()` / `saveSettings()` - управление настройками приложения

**CSS (style.css):**
- `.side-menu` - стили бокового меню
- `.treasure-close-btn` - кнопка закрытия панели сокровища
- `.modal-close-btn` - кнопки закрытия модальных окон
- `.settings-group` - стили группы настроек

## 📱 Использование

### Открытие меню:
1. Нажмите ☰ в левом верхнем углу
2. Выберите нужный раздел
3. Для закрытия нажмите на область вне меню или крестик

### Просмотр сокровища:
1. Нажмите на маркер сокровища на карте
2. Откроется панель с информацией и изображением
3. Для закрытия нажмите × в правом верхнем углу панели

### Настройка AI-изображений:
1. Меню → Настройки
2. Включите/отключите "Генерация AI-изображений"
3. При следующем открытии точки изображение будет сгенерировано автоматически
